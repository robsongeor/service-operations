# Customers, Sites and Contacts

This guide covers the Customer, Site and Contact actions available to Auckland **Job Book Admins**
and **Office Admins**.

## Search before creating

Customer, Site and Contact records are shared. Creating a duplicate makes Equipment and Job history
harder to find.

Before creating anything:

1. Search the complete Customer name and a shorter part of the name.
2. Check the Customer's existing Sites and addresses.
3. Check the Site's Contact list.
4. Create a record only when the correct one does not already exist.

## Use the Customers screen

1. Open **Customers**.
2. Search for and select the Customer.
3. Use the available tabs:
   - **Sites** shows Sites and the Equipment recorded at each location;
   - **Jobs** shows the Customer's Jobs;
   - **Contacts** shows Customer-wide and Site-linked Contacts;
   - **Info** shows accounts information, purchase-order requirements and long-term notes; and
   - **Quotes** is also visible to Office Admins.

Job Book Admin and Office Admin access is intentionally restricted. These roles can view Customer
information but cannot directly edit the Customer's accounts contact, accounts phone, accounts
email, purchase-order requirements or long-term notes. Send the exact requested correction to an
authorised administrator.

## Create a Customer and its first Site

Restricted roles can create a Customer with its first Site from the Customer selector.

1. Open **Customers** and search carefully for the Customer.
2. If no correct result exists, use the create option in the Customer selector.
3. Enter the Customer name, first Site name and verified address.
4. Check the spelling and address.
5. Save once and wait for the confirmation.

The Customer and Site are saved immediately. Leaving a later Job form does not remove them.

## Create a Site while creating a Job

1. Select the existing Customer.
2. Open the **Site** list.
3. Select **+ Add new site**.
4. Enter the Site name.
5. Search for the address and select a verified suggestion. Typing an address without selecting a
   suggestion is not enough.
6. Select **Create site** and wait for the new Site to become selected on the Job.

The Site's address becomes the Job address. If the address is wrong, fix the shared Site through an
authorised workflow rather than typing a different address into one Job.

## Create a Contact while creating a Job

1. Select the Customer and Site first.
2. Open the **Contact** list.
3. Select **+ Add new contact**.
4. Enter the Contact name and, when known, phone and email.
5. Select **Create contact** and wait for the new Contact to become selected.

The Contact is linked to the selected Site. The **Contacts** tab currently displays existing
Contacts, but its general **+ Add Contact** action is not yet enabled for these roles. Create a new
Site Contact from a new Job form when the Contact is needed for that Job.

## Move Equipment to the correct Site

Use **Transfer Equipment** only when the machine's real current location has changed.

1. Open the Customer and expand the destination Site.
2. Select **Transfer Equipment**.
3. Search for the machine and check its current Customer and Site.
4. Select the intended machine and confirm the destination.
5. Save the transfer.

A transfer changes the Equipment's current location. It does not rewrite historical Jobs or create a
copy of the Equipment.

## Important restrictions

- Do not create a duplicate Customer because its information needs correcting.
- Do not create a second Site merely to change the spelling of an existing one.
- Creating a Customer, Site or Contact is a separate saved action and is not undone when a Job form
  is cancelled.
- General Customer information editing and general Contact administration are not enabled for these
  rollout roles.

## If something goes wrong

If a Customer was saved but its Site failed, do not create the Customer again. Search for the saved
Customer, then add or report the missing Site. Include the exact message and a screenshot when
requesting help.

Hold **Windows key + Shift + S**, select the affected area, then paste the screenshot into your
support email.
