# Equipment guide

This guide covers the restricted Equipment workflow available to Auckland **Job Book Admins** and
**Office Admins**.

## Find Equipment

1. Open **Equipment**.
2. Search by GT Equipment number, alternate fleet number, serial number, make or model.
3. Check the Customer, Site and machine details before opening a result.

Search by more than one identifier when the first result is uncertain. Former or Customer-specific
fleet numbers may appear under **Alternate Fleet Numbers**.

Most Equipment from GreenTree is already present in Service Operations. The GreenTree Equipment
load did not automatically create or assign all Customers and Sites, so some machines may have no
current location relationship yet. Do not create duplicate Equipment when the machine can already
be found.

If the correct Customer or Site does not exist, create the missing relationship record through the
available location editor. New Site addresses must be selected from the verified New Zealand address
suggestions. The search can take a few seconds, and a manually typed free-text address cannot be
saved.

## Details these roles can maintain

Open an Equipment record to update approved master details, including:

- GT Equipment number;
- serial number;
- alternate fleet numbers;
- make and model;
- current Customer and Site;
- whether the machine is used on the road;
- registration number and REGO expiry; and
- current WOF expiry.

Recheck the machine and location before selecting **Save changes**. Changing the GT Equipment number
keeps its previous value as an alternate fleet number so it remains searchable.

## Move Equipment

Change the Equipment location only when the physical machine has genuinely moved.

1. Open the Equipment record, or use **Transfer Equipment** from the destination Customer Site.
2. Select the correct Customer and Site.
3. Check the destination address.
4. Save once and wait for confirmation.

If the destination Customer or Site is missing, search again before creating it. When creating a
Site, wait for the address suggestions and select the correct verified result.

The move changes the current Equipment location. Historical Jobs keep the Customer, Site and address
that were recorded when those Jobs were created.

## WOF and REGO details

Turn on **Road use** only for Equipment that requires road-compliance information. Check the
registration number, REGO expiry and WOF expiry carefully before saving.

Turning off Road use or changing compliance details affects the shared Equipment record. Stop and
request help when the correct compliance state is uncertain.

## Restricted actions

Job Book Admins and Office Admins do not have the full Equipment-management workflow. In particular,
these roles should not expect to:

- create a new Equipment record from the Equipment screen;
- delete Equipment;
- change maintenance programmes or service baselines;
- change Equipment ownership or Site Check availability; or
- edit full Job history from the Equipment screen.

If no matching Equipment exists when creating a Job, use **Equipment not known yet** only when work
must be recorded immediately, then report that the Equipment record needs to be created or
reconciled. Do not invent a near-matching fleet or serial number.

## If a save fails

Do not create replacement Equipment. Reload the record, check whether the change was saved, and try
once more only when the app instructs you to. Report the machine identifier, intended change, exact
message and a screenshot if the problem remains.
