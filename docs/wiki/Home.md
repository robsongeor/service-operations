# Service Operations user guides

Welcome to the user guide for Service Operations.

These guides explain the everyday tasks available to your assigned role. The options you see may
be different from another person's because access is matched to the work each person performs.

spreadsheet. Waikato, Hastings and Christchurch will continue using their existing processes until
a separate change is announced.

## Important rules

- Search before creating a Job, Customer, Site or Equipment record.
- Check every Job carefully before selecting **Add to Job Book**. A permanent Job Number cannot be
  deleted, reused or undone after it has been allocated.
- Do not create a second Job while the first save or TimeCloud upload is still pending.
- Bulk Job creation and Site Check creation are not available in this release.
- TimeCloud creation is live in production mode. Its status is automatic and read-only.

## Need help?

Report problems as soon as possible. Include what you were trying to do, what happened and the
exact message shown on screen.

To include a screenshot on Windows, hold **Windows key + Shift + S**, select the affected area,
then paste the screenshot into your support email. Never include a password or verification code.
